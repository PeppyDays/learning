# Learning

Personal study repository with AI tutor. Each topic gets its own directory with a curriculum and notes.

## Structure

```plaintext
learning/
  <topic>/
    CLAUDE.md     # curriculum and progress tracker
    notes/        # study notes
```

## Starting a new topic

1. Open Claude Code in this directory
2. Paste the contents of `PROMPT.md` into the chat
3. Claude will interview you and generate a `<topic>/CLAUDE.md` with a curriculum
4. Open Claude Code inside the new topic directory to start studying

## Studying

```plaintext
# Start from the beginning
"Let's start from Phase 1-1"

# Resume where you left off (new session)
"Let's pick up where we left off"

# Check progress
"Where did we get to?"
```
